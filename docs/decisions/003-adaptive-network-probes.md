# ADR-003: 全链路网络探针与零配置自适应镜像

## 状态
已采纳 (Accepted) - 2026-09-18；2026-09-30 补充探测与回退行为。

## 背景
国内用户直接访问 Hugging Face 或官方 PyPI 常常遭遇超时、丢包或下载失败，要求普通用户配置代理会极大提高使用门槛。

## 决策
启动时后台静默执行并发网络测速探针（`engine/core/network_probe.py`），自动决定最佳模型源与 PyPI 源。

## 理由
1. 使用启用 TLS 校验的 HEAD 请求探测可达性和延迟，探测有超时；根据结果选择模型源与 PyPI 源，而非通过 IP 地理定位识别国家。
2. 下载依次尝试所选来源和备用来源，ModelScope / Hugging Face / HF Mirror 分目录缓存；安装入口尝试清华/官方 PyPI。前端允许自动选择或明确选择来源。
3. 自动适配减少手动配置需求，但网络、源端资源与认证仍可能导致失败；界面展示实际错误与下载进度，不保证所有网络均可连接。
