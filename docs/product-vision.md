# Voxera 产品规格

Voxera 面向需要设计角色声音、比较多个候选并复用音色生成台词的创作者。当前为本地 Windows Alpha 工作台。

## 核心流程

创建角色 → 填写音色描述/台词 → 选择模型 → 默认生成 4 个候选（支持 1–10） → 横向试听 → 设为正式音色 → 勾选复用，生成新台词 → 导出 WAV / ZIP。

定型保存一个有效候选的绑定；复用真正传递参考音频。Qwen 需 Base 模型，未下载时给出明确提示。复用的稳定性依赖上游模型，不能保证不同文本完全一致。

## 交互约束

- 暗色玻璃材质、清晰字体、低干扰；品牌字标 VOXERA，正文 Voxera。
- 所有设备保留 1–10 候选，CPU 通过串行和进度骨架等待，不缩减选择。
- 生成、下载、失败、断线与就绪均根据实际结果显示；刷新恢复任务追踪。
- 同时只播放一个音频；弹窗支持焦点限制、Esc 与焦点恢复。
- 中文/英文、暗色/亮色；桌面最小窗口 960×640。关键字段有长度和非空校验。
- 普通流程不要求调整底层参数；候选可展示 Seed/版本/耗时供追溯。

## 当前边界

不提供多人服务、云推理、训练或实时变声。CPU 可运行但速度取决于硬件，CUDA/MPS 的可用性依赖正确安装的 Torch 和驱动。Tauri 和其他平台的发行尚未交付。许可、隐私和测试范围按 README / SECURITY / 实现报告描述，不使用未经验证的离线、零痕迹或性能承诺。
